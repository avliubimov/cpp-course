# Введение в C++

C++ — это компилируемый, статически типизированный язык программирования общего назначения, поддерживающий различные парадигмы: процедурную, объектно-ориентированную и обобщенную.

## Пример кода

Ниже приведен классический пример программы "Hello, World!" с современным синтаксисом C++ (C++11 и выше):

```cpp
#include <iostream>
#include <vector>
int main() {
// Инициализация вектора с помощью списков инициализации
std::vector<int> numbers = {1, 2, 3, 4, 5};
// Range-based for loop (цикл по диапазону)
for (const auto& num : numbers) {
    std::cout << num << " ";
}

std::cout << std::endl;
return 0;
}
```


## Оценка сложности

При анализе алгоритмов мы часто используем "O-нотацию" (Big O notation). Например, сортировка слиянием (Merge Sort) имеет временную сложность:

$$
T(n) = O(n \log n)
$$

Где $n$ — это количество элементов в массиве. Это означает, что время выполнения растет пропорционально $n \log n$.

> **Заметка:** В будущих лабораторных работах мы будем измерять реальное время выполнения и сравнивать его с теоретической оценкой.
